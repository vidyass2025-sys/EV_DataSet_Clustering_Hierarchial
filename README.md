# Electric Vehicle (EV) Dataset Clustering & Segmentation

- Python
- Hierarchical Clustering
- Unsupervised Machine Learning
- Scikit-Learn
- Seaborn / Matplotlib

- `EV_Dataset_Analytics_Project_Report.docx`
